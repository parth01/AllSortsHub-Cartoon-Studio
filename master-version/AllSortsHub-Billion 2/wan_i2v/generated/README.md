# Wan-generated clips

Put the generated Wan 2.2 MP4 clips in this directory.

For shots longer than one generation pass, use:

- `shot_01a.mp4` + `shot_01b.mp4`
- `shot_02a.mp4` + `shot_02b.mp4`

For shots that fit one pass, use `shot_XX.mp4`.

Do not commit Wan model weights or ComfyUI caches here.
