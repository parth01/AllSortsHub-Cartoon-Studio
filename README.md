# AllSortsHub Cartoon Studio

A lightweight, original 2D cartoon production engine for AllSortsHub.

## Episode 1
**The Guy Who Got $1 Billion for One Day**

## Run locally
```bash
python3 -m pip install pillow
python3 studio.py
```

FFmpeg is optional for frame generation and required for MP4 rendering.

## Project goal
Create original recurring characters and stories, then turn one episode into a long YouTube video plus multiple Shorts.

The current engine is intentionally lightweight: it creates original vector-style cartoon scenes and subtitles. Future versions will add character motion, voice tracks, sound effects, camera movement and automatic Shorts rendering.
